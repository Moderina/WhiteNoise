# WhiteNoise
## Music Player App for Android 15

This music app is built for simplicity of usage with many useful features:
- auto title and artist parser
- pagination of music list for better performance and responsiveness
- customizability (each song can have its own unique color for background)
- related image to song online finder
- youtube search and play
